# 🛡️ Cyberbullying Tweet Classification

This project focuses on detecting and classifying tweets that contain cyberbullying content. Using a labeled dataset of tweets, we aim to build a multi-class text classification model capable of identifying various types of cyberbullying.

---

## 📂 Dataset

The dataset used is `cyberbullying_tweets.csv`, which contains:

- **tweet_text**: The actual tweet text
- **cyberbullying_type**: Label indicating the type of bullying or `not_cyberbullying`

**Classes include:**
- `gender`
- `religion`
- `age`
- `ethnicity`
- `other_cyberbullying`
- `not_cyberbullying`

---

## 🛠️ Technologies Used

- **Python** (Data analysis and model development)
- **Pandas & NumPy** – Data processing
- **Matplotlib & Seaborn** – Data visualization
- **NLTK** – Text preprocessing
- **Scikit-learn** – ML models and evaluation
